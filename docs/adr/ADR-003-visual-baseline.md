# ADR-003: Existing UI as Canonical Initial Visual Baseline

Status: Accepted

## Decision
The existing React UI in this repository is the canonical visual reference for the initial product. Its demonstrated layout, navigation treatment, typography, spacing, component proportions, forms, tables, cards, and responsive behavior are preserved while the underlying prototype architecture is replaced as necessary.

## Constraint
Backend architecture, persistence changes, or domain modeling are not valid reasons to redesign the UI. New surfaces must reuse or minimally extrapolate established patterns.
