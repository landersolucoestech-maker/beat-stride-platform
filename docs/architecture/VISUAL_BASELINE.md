# Visual Baseline

Status: Active

## Canonical shell
The current frontend is the initial visual reference. The shell consists of a fixed left sidebar, sticky top bar, light dashboard canvas, rounded cards, subtle borders, Inter typography, compact iconography, and a teal primary accent.

## Preservation rules
- Preserve sidebar width, top-bar composition, content spacing, card radius, border treatment, typography hierarchy, and responsive behavior unless a demonstrated defect requires correction.
- Preserve the current dashboard composition: wallet and quick actions, recent releases, performance cards, rankings, charts, and territories.
- New product surfaces reuse the same primitives and visual density.
- Architecture evolves behind the UI instead of forcing an unsolicited redesign.
- Prototype business data is never production truth. Fake balances, streams, artists, releases, rankings, territories, royalties, and financial values must not be presented as real state.
- Empty, loading, unavailable, and error states preserve the same visual language.

## Navigation
Navigation labels are end-user pt-BR. Internal route and module names remain English. Menu changes are driven by approved product scope, not speculative redesign.

## Review
Every material frontend mission is reviewed against the GitHub Pages preview at representative desktop and mobile widths.
