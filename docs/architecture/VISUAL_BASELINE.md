# Visual Baseline

Status: Active

## Canonical shell
The current frontend is the initial visual reference. The shell is composed of a fixed left sidebar, sticky top bar, light editorial dashboard canvas, rounded cards, subtle borders, Inter typography, compact iconography, and a teal primary accent.

## Preservation rules
- Preserve the existing sidebar width, top-bar composition, content spacing, card radius, border treatment, typography hierarchy, and responsive behavior unless a demonstrated defect requires correction.
- Existing dashboard composition remains the baseline: wallet and quick actions, recent releases, performance cards, rankings, charts, and territories.
- New product surfaces reuse the same primitives and visual density.
- Domain architecture must adapt behind the UI rather than forcing an unsolicited redesign.
- Prototype business data is not production truth. Fake balances, streams, artists, releases, rankings, and financial values must be progressively removed as real vertical slices are connected.
- Empty, loading, error, and unavailable states must preserve the same visual language.

## Navigation
Navigation labels are end-user pt-BR. Internal route/module names remain English. Menu changes are driven by approved product scope, not by speculative redesign.

## Review
Every material frontend mission must be reviewed against the GitHub Pages preview at representative desktop and mobile widths.
